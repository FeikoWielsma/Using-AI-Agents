# Using AI Agents

Explore useful tool calls, MCP connections, agents working together, guardrails,
human approval and coding-agent harnesses. Five independent challenges use
different fictional scenarios. No code editing is required.

## Start here

Use the **Explore** route in the browser lab with your course code. The rebuilt
route is included in this repository; the hosted version changes when the trainer
deploys it. [Browser lab](https://agent.feikowielsma.nl).

Read the [five challenges](handouts/practicals.md) and [browser guide](handouts/browser-lab.md).
The [Colab companion](https://colab.research.google.com/github/FeikoWielsma/Using-AI-Agents/blob/main/notebooks/explore-AI-agents.ipynb)
is an alternative after these files are published to the student repository.

| Module | Challenge | Time |
| --- | --- | --- |
| 1. Tools that do useful things | A team outing becomes a working Excel comparison | 12 min |
| 2. Connecting services with MCP | An appointment appears in the course calendar | 10 min |
| 3. Agents working as a team | Two specialists design a pop-up cafe together | 12 min |
| 4. Guardrails and human decisions | A refund hits a limit, then waits for a person | 10 min |
| 5. Coding agents and their harnesses | A coding agent repairs a tiny calculator | 15 min |

## Capstone: open your café

Build a working pop-up café with agents, approve ingredient spending and opening, then handle a lunch rush and a surprise. [Open the capstone](https://agent.feikowielsma.nl/cafe) · [Challenge guide](handouts/cafe-capstone.md). Allow 30 minutes.

The lab creates an Excel file and runs separate specialist agents. Its refund
ledger is a local fictional sandbox. The MCP service provides a real protocol
connection and persistent course calendar/task records. The browser mini harness
interprets a limited arithmetic expression; the trainer demonstrates full coding
products separately. No real customer, employer, payment or fitness account is used.

All core activities work in the browser without installing software. Downloads
are optional. Vendor harness demonstrations use trainer accounts.

Download useful outputs before course access ends. Vendor harnesses use their own
accounts and permissions; a course code does not unlock those products.
