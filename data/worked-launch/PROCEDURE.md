# Evidence review procedure

## Required inputs
Current task brief, effective checklist, dated source records and decision register.
## Steps
1. Read the brief, memory and current checklist. Verify the version and scope.
2. Identify the evidence needed for each material completion claim.
3. Read the relevant records. Check IDs, dates, results and unresolved conditions.
4. Reconcile conflicting statements without silently changing an approved decision.
5. Draft a sourced result. Separate supported facts, assumptions, questions and decisions needed.
6. Propose updates to memory and the result. Explain which new source changed a fact.
7. Review and apply accepted file changes; export the workspace.
## Stop conditions
Missing evidence remains open. Ask the responsible person for an approval or external action.
## Completion check
Another reviewer can trace the important claims to the supplied records.
