# Calculator starter

This fictional calculator contains one deliberate bug. Extract into a new folder.
Ask a coding agent to repair it. You do not need to type Python.

Prompt: Read PROJECT-INSTRUCTIONS.txt. Fix the calculator and run its checks.

Next: Add a 10% discount when the subtotal is at least EUR 50. Extend the checks
for just below, exactly at and above the threshold. Keep previous behaviour for
smaller orders. Run the checks again.

Optional: make a small local browser interface for the calculator.

Start each vendor comparison from a fresh copy. The trainer handles tool setup.
