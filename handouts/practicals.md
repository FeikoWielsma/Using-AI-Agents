# Five short challenges

Use one activity at a time. Each starts independently. Optional stretches are for spare time.

| Module | Challenge | Time |
| --- | --- | --- |
| 1. Tools that do useful things | A team outing becomes a working Excel comparison | 12 min |
| 2. Connecting services with MCP | An appointment appears in the course calendar | 10 min |
| 3. Agents working as a team | Two specialists design a pop-up cafe together | 12 min |
| 4. Guardrails and human decisions | A refund hits a limit, then waits for a person | 10 min |
| 5. Coding agents and their harnesses | A coding agent repairs a tiny calculator | 15 min |

## 1. Tools that do useful things

Six fictional activities, six different prices. Organise an outing for eight people.

**Starting request**

> Find two indoor activities for eight people costing at most EUR 300 in total. Use the catalogue and quote tools, then create an Excel comparison with formulas and a chart.

1. Run the request and inspect the comparison in the browser.
2. Change the group size in the browser preview and see the totals update.
3. Ask the agent for a different budget or indoor preference and compare the result.

**Finish:** One usable spreadsheet and one change you requested.

**Optional:** Ask for a three-slide pitch using the same recommendation in a trainer harness with presentation tools.

## 2. Connecting services with MCP

A fictional fitness diary and a connected calendar. No personal account is required.

**Starting request**

> Inspect the fitness diary and calendar. Find a free 20-minute planning-review slot on Thursday 10 September 2026 after the business trip. Propose one event and wait for my review.

1. Select the Fitness diary scenario in this activity.
2. Connect with proposal access, run the request, and review the proposed appointment.
3. Approve and apply it, then inspect the calendar below.

**Finish:** An appointment in your isolated course calendar.

**Optional:** Switch to read-only access and ask for another appointment. Discuss what changes.

## 3. Agents working as a team

A pop-up cafe needs a menu for 20 visitors, within EUR 100 ingredient cost.

**Starting request**

> Design a three-item pop-up cafe menu for 20 visitors within EUR 100 ingredient cost. Combine an appealing concept with a workable cost estimate. Include a vegan option.

1. Run with the two specialists and read their separate contributions.
2. Change the second specialist from operations to accessibility and run again.
3. Compare with a solo run. Discuss whether the extra agent helped.

**Finish:** A menu proposal shaped by two separate agent runs.

**Optional:** Give the specialists conflicting priorities and ask the coordinator to resolve the tradeoff.

## 4. Guardrails and human decisions

A fictional shop offers refunds up to EUR 50 for order SHOP-104. No money moves.

**Starting request**

> Look up order SHOP-104 and propose a EUR 40 goodwill refund. Explain the reason in one sentence.

1. Ask for an EUR 80 refund and observe the enforced limit.
2. Request EUR 40, inspect the proposal, then reject it.
3. Run again, approve the new proposal and inspect the sandbox ledger.

**Finish:** You have tried a blocked action, a rejection and an approval.

**Optional:** Tell the agent to ignore the limit. The tool must still enforce it.

## 5. Coding agents and their harnesses

A calculator adds price and quantity instead of multiplying. The prepared checks fail.

**Starting request**

> Repair the calculator so total(price, quantity) returns the order total. Read the project instructions, edit the expression, and run the checks. Keep the function name and use no dependencies.

1. Run the mini harness and try the repaired calculator.
2. Select the discount requirement and ask for the change.
3. Watch the trainer run the same starter in Codex, Claude Code or Antigravity CLI. Compare the visible controls.

**Finish:** A repaired calculator and an understanding of what the harness supplies.

**Optional:** Ask the trainer to use the starter ZIP in a coding harness and add a small browser interface. Student practice stays in the browser.
