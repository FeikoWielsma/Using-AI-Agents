# Browser lab

Open the trainer's Explore lab and enter your course code. Choose a module,
read the short task and press **Run the agent**. Open what it made. Add a follow-up
request when you want a change. **Tools used** is available when you are curious.

- Module 1: inspect the interactive comparison. Change People and press Update totals.
  The Excel download is optional and no spreadsheet application is required.
- Module 2: connection access, input documents, proposals and the calendar are available in the same activity.
  Select Fitness, then Read & propose and Set connection. Run the request, inspect
  the time, approve the proposal and apply it. **Verify destination** opens the
  saved calendar/task records. Use the site logo to return to Explore.
- Module 3: try Two specialists + coordinator. Change the second specialist or
  select One agent. Each run uses the same task with fresh agent contexts.
- Module 4: the refund limit is EUR 50 cumulatively. Try EUR 80, reject a EUR 40
  proposal, then approve another. **Reset this activity** clears only this local
  fictional scenario, its output files and attempts. It does not reset MCP records.
- Module 5: repair the calculator, then select the discount requirement. Try the
  result with different prices and quantities. The mini harness cannot run arbitrary
  programs; use the starter ZIP for a full coding product demonstration.

Keep the browser open during a run. If disconnected, use Refresh before retrying.
Each course account has its own saved activities. New requests keep recent attempts
for comparison. Reset removes them. Download files you want to keep.

**More examples** opens the earlier Markdown workspace and trace-review activities.
Those are optional. The new route has no required brief, evidence form or workspace ZIP.
